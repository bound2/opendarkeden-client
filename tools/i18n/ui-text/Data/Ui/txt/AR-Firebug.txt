Essential gear for special forces, this is a shortened model of the U.S. military's standard rifle. The top, where the carrying handle used to be, was converted to a Picatinny rail so that scopes and other accessories can be fitted and removed easily; any equipment built to the standard can be attached or detached within seconds. This version, improved by E.V.E, comes with a grenade launcher fitted as standard and accepts a range of detachable options. A twin-barrel model that lives up to the name 'Firebug'.
