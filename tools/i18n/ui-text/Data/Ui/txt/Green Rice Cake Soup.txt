An event item prepared by DarkEden for Seollal, the great Korean Lunar New Year holiday. It can add an option to an item that has none.
Only premium users can use it. It can be used, traded, handed over and sold to shops.

Green Rice Cake Soup is an enchant rice cake that grants DEX+1 to an item with no options, and the enchant always succeeds whatever the type of item.
